# One Thought

A one-line daily page. Same thought for the calendar day. Offline after the first visit. Add it to your phone’s home screen and it opens like an app.

Live site:

https://bortniky-dotcom.github.io/one-thought/

## Add to the home screen

### iPhone
1. Open the page in Safari
2. Share → Add to Home Screen

### Android
1. Open the page in Chrome
2. Menu → Add to Home screen / Install app

True widgets are not available to a web page. The home-screen shortcut is the practical version of that.

## How a line is chosen

- Stays put for the local calendar day
- Avoids near-duplicates of the last 30
- Avoids the same theme more than twice in 7 days
- Avoids the same opening phrase two days in a row
- Mixes focus, family, discipline, perspective, and patience
- “Another” replaces today’s line if you want a different one

Everything is stored in the browser. Nothing is sent anywhere.
